# P1-01 设计：光先对（镜面、GGX + 菲涅尔、NEE + MIS，仅球与平面）

> 状态：**已确认并实现**（2026-10-25，P1D1–P1D13 全部按默认）。实现交付与实测数字见 [`P1-02-implementation.md`](P1-02-implementation.md)；实现中与本文不一致的地方记在文末「实现修订」，正文保留设计时的原样。
> 候选赛结果（P1-02 的 F1–F4，2026-10-25 全部按默认）：耦合 Kelemen（P1D2），MIS 权重 **balance**（P1D7，原默认 power），GGX 采样 **球冠法**（P1D8，原默认 VNDF），球光源锥采样（P1D9）。
> 方向已定（2026-10-25）：对外只用 JSON + patch；严格按 P1 → P2 → P3 → P4；实时光栅预览放 P3/P4；几何按原文档。
> 原文档对 P1 的要求：Lambert → 理想镜面 → GGX + 菲涅尔 + MIS，仅球与平面。验收：误差低于阈值，且收敛斜率通过 1/√N 检验。画面可以丑，数字必须对。

## ① 一句话目标与本次决策点

**目标**：在不破坏 P0 任何一个字节的前提下，把材质扩展到"金属度 / 粗糙度 / IOR"三参数的微表面模型，并加入点光源、球面光源的直接光采样（NEE）与多重重要性采样（MIS）。每一项都先有解析解或数值积分的裁判。

**决策点**（★ 为默认；回复 `P1D1A …` 或"全部默认"）：

| # | 分歧点 | 选项 | 依据 / 影响 |
|---|---|---|---|
| **P1D1** | v2 材质参数 | **A★** 新增 `metallic`、`roughness`、`ior`，是七参数模型的子集；SSS / clearcoat / anisotropy 留到 P3。默认值 `metallic 0, roughness 1, ior 1.0`，在这组默认值下 v2 材质与 v1 的 Lambert **逐位相同**（ior = 1 时菲涅尔为 0，没有镜面层）。<br>**B** 一次加齐七个参数，未实现的报 `E_UNSUPPORTED`。 | 延续 P0 的 D4-A："schema = 当前能力"。 |
| **P1D2** | 非金属的"漫反射 + 镜面"耦合方式 | **A★** 进候选赛：Kelemen & Szirmay-Kalos 2001 耦合（漫反射乘 (1−E_s(μi))(1−E_s(μo))/(1−Ē_s)，E_s 为镜面层方向反照率，CPU 用 f64 数值积分建表后上传）对比 Ashikhmin & Shirley 2000 的解析耦合；朴素的 F 加权混合只作负对照（它不满足互易性，必须被互易断言抓到）。<br>**B** 直接用 Ashikhmin-Shirley。 | 两者都互易、能量 ≤ 1；Kelemen 在任意 IOR 下精确守恒，但要建表；Ashikhmin-Shirley 绑定 Schlick 近似。 |
| **P1D3** | GGX 单次散射的能量损失（高粗糙度下白炉 < 1） | **A★** 保留单次散射模型。白炉裁判的期望值改为数值积分得到的 E_ss(μ, α)，而不是 1。<br>**B** 加 Kulla & Conty 2017 多次散射补偿，让金属白炉回到 1（需要再建两张表）。 | A 的数字是"对"的：模型本身就会损失能量，裁判比较的是模型的精确值。B 留作 P3 材质层的候选。 |
| **P1D4** | 粗糙度到 α 的映射 | **A★** α = roughness²（Burley 2012，Disney / UE4 惯例）<br>**B** α = roughness | 只影响参数的直觉尺度，不影响正确性。 |
| **P1D5** | 粗糙度 = 0（原文档列出的极端输入） | **A★** α < α_min = 10⁻³ 时切换为精确的 δ 镜面波瓣，不再走 GGX 公式（GGX 在 α → 0 时 D 发散）；连续性由 G30 检验：α 从上方逼近 α_min 时，图像逐步收敛到 δ 镜面的结果。<br>**B** 把 α 截断到 ≥ α_min，永远不出现真正的 δ 波瓣。 | 原文档要求"理想镜面"，B 做不到。 |
| **P1D6** | 菲涅尔 | **A★** 非金属：精确的非偏振介质菲涅尔方程（PBRT-v4 第 9 章 FrDielectric）；金属：F0 = base_color 的 Schlick 1994。七参数模型里没有复折射率，金属只能这样。<br>**B** 全部用 Schlick。<br>**C** 金属用复折射率（要新增 η、k 参数）。 | A 让 G22（介质镜面球）可以逐像素对照精确菲涅尔方程。 |
| **P1D7** | MIS 权重 | **A★** 进候选赛：power heuristic β = 2 对比 balance heuristic（Veach 1997 §9.2）；默认 power。<br>**B** 直接用 balance。 | balance 有 Veach 定理 9.2 的方差上界，可以直接写成断言；power 一般更好，但没有同样干净的上界。 |
| **P1D8** | GGX 采样 | **A★** 进候选赛：可见法线采样 VNDF（Heitz 2018，JCGT 7(4)）对比球冠法（Dupuy & Benyoub 2023，CGF）；完整 NDF 采样 D(m)cos 只作基线。 | VNDF 的权重恒为 F·G2/G1 ≤ 1，正好让逐样本能量上界继续成立。 |
| **P1D9** | 光源类型 | **A★** 点光源（发光强度 cd，δ 光源，只能 NEE）；自发光的球自动成为面光源（按立体角做均匀锥采样，PBRT-v4 第 6 章）；环境光（constant / split）也参与 NEE；自发光平面无限大、无法采样，只靠 BSDF 采样命中。<br>**B** 另加聚光灯。<br>**C** 只用自发光几何体，不加点光源。 | 单位表里预留的 `cd` 在这里启用。 |
| **P1D10** | 光源选择概率 | **A★** 按功率比例，在 CPU 上用 f64 算好上传（确定性）<br>**B** 均匀选择 | |
| **P1D11** | 随机维度布局 | **A★** BSDF 维度保持 P0 的 `dim_block = 1 + b` 不变；NEE 用另一段 `0x80000000 + b`。这样 v1 场景迁移到 v2、以 `strategy: "bsdf"` 渲染时与 P0 **逐字节相同**，p0 的全部 golden 不需要重录。<br>**B** 重新设计维度布局，p0 golden 按 ADR 重录。 | A 让"迁移不改变图像与状态的任何字节"成为对重构最强的回归测试。`metrics.json` 会多出 P1 的新指标，所以它的哈希除外，只比较原有字段。 |
| **P1D12** | 估计器在场景里怎么表达 | **A★** `render.integrator: "pt_p1"` 加 `render.strategy: "bsdf" \| "nee" \| "mis"`（默认 `mis`）；迁移把 v1 的 `pt_bsdf_p0` 映射为 `pt_p1 + strategy: "bsdf"`。<br>**B** strategy 不进 schema，只作运行选项。 | strategy 会改变噪声（输出字节），不属于"不得改变输出"的执行计划，所以应进 schema；三种策略同时也是 MIS 无偏性断言的对照组。 |
| **P1D13** | NEE / MIS 下的能量校验器 | **A★** 逐样本上界只对 `strategy: "bsdf"` 成立（NEE 的单个样本可以任意大）；对 `nee` / `mis` 改为统计判据：像素均值 ≤ B·(1 + τ) + kσ̂，σ̂ 由 m2 估计。<br>**B** 一律只用统计判据。 | 必须改：否则 V-Energy 会在合法的 NEE 场景上误报。 |

## ② 测试先行

### 新增黄金场景（p1，绑定 schema v2）

裁判有三类：**回放**、**数值积分**、**统计**。

**回放**用于路径确定的场景（δ 波瓣、点光源、D = 1）：CPU 用 f64 重新生成与 GPU 完全相同的 Philox 抖动，逐样本解析地算出期望值。期望像素值因此与估计器只差 f32 误差，不需要统计容忍度。容忍度由 f32 几何误差预算推导（交点、法线各若干 ulp，传到菲涅尔、余弦），实现时写进 `tol.derivation`。

| id | 场景 | 断言（数学形式） | 容忍度来源 |
|---|---|---|---|
| G21 `mirror_sphere_constant_env` | 金属、base 1、roughness 0（δ）、常量环境 1、D = 1、凸球 | I = 1（F0 = 1 时 Schlick 恰为 1） | 同 G08 的 (spp−1+5D)·u；同时是 δ 波瓣的自交探测器 |
| G22 `dielectric_mirror_fresnel` | 非金属、base 0、roughness 0、ior 1.5、常量环境 1、D = 1 | 逐像素 I(p) = (1/N)·Σ_s F_diel(μ(p, s), 1.5)，μ 由回放的抖动光线求得 | 回放 + f32 误差预算 |
| G23 `ggx_conductor_furnace` | 金属、base 1、roughness ∈ {0.2, 0.5, 1}、常量环境 1、D = 1、凸球 | 按出射角分 16 个径向环：环均值 = 环内 E_ss(μ, α) 的平均（E_ss 由 f64 自适应求积给出），误差 ≤ 5σ̂/√n | 求积误差 < 10⁻⁸，加 Bonferroni 5σ |

## ③ 实现设计

### 3.1 schema v2（相对 v1 的差异）

| 位置 | 新字段 | 单位 / 范围 | 默认 |
|---|---|---|---|
| `materials.*` | `metallic` | 1，[0, 1] | 0 |
| `materials.*` | `roughness` | 1，[0, 1] | 1 |
| `materials.*` | `ior` | 1，[1, 3] | 1.0 |
| 顶层 | `lights`：id → `{ type: "point", position_m, intensity_cd, color }` | m；cd，[0, 10⁹]；1 | 无 |
| `render` | `integrator` 改为 `"pt_p1"`；新增 `strategy` | 枚举 | `"mis"` |

- 新的语义检查：点光源不能落在任何球体内部（`E_LIGHT_INSIDE`）；光源 id 与物体 id 的命名空间分开，但同样做 idhash 碰撞检查。
- 迁移 `migrate_v1_to_v2`：补上材质默认值；`pt_bsdf_p0` 改为 `pt_p1 + strategy: "bsdf"`；`v: 2`。
- 回滚 `rollback_v2_to_v1`：只有当 metallic = 0、ior = 1、没有 `lights`、strategy = "bsdf" 时才无损，否则报 `E_ROLLBACK_LOSSY` 并列出路径。
- 运行时只执行最新版本。旧版本的场景在加载时自动迁移，manifest 记录迁移链。

### 3.2 BSDF（`bsdf_p1.wgsl`，渲染与探针共用）

- **金属**：f = D·G2·F_schlick(base_color) / (4μiμo)。D 为 GGX（Walter et al. 2007），G2 为高度相关 Smith（Heitz 2014，JCGT 3(2)）。
- **非金属**：f = f_spec(F_diel(ior)) + f_diffuse_coupled(base_color)，耦合方式由候选赛（P1D2）决定；ior = 1 时 f_spec = 0，耦合因子为 1，整个式子化为 Lambert，并且代码路径与 P0 **完全相同**（这是 P1D11 逐字节相同的前提）。
- **金属度**在两者之间线性插值；波瓣选择用 BSDF 维度块的 u2，概率按两个波瓣的反照率估计。
- **δ 波瓣**（α < α_min）：单独的分支。其 pdf 记为"δ"，MIS 时只走 BSDF 一侧，权重为 1。
- **数值守卫**：μ = 0、α → 0、半向量退化（ωi = −ωo）都有显式分支，不依赖 NaN 传播（N9）。

### 3.3 积分器（`render_p1.wgsl`）

- 每次相交：先做 NEE（光源选择用 `0x80000000 + b` 块的 u0，光源上的位置用 u1、u2），再做 BSDF 采样（`1 + b` 块）。
- MIS 权重由候选赛决定（P1D7）。命中自发光几何体时，用光源 pdf 计算 BSDF 一侧的权重；平面光源只有 BSDF 一侧。
- 能量校验器按 P1D13 分两种判据。
- **执行计划不变性**（N6）、**每像素按样本顺序累加**（N4）都照旧，G03 的 5 种计划扩展到 p1 场景上同样要求逐字节相同。

### 3.4 机制 ① 候选赛（P1 的默认工作模式）

| 候选集 | 候选 | 评分基准 |
|---|---|---|
| C-Coupling | Kelemen 2001 / Ashikhmin-Shirley 2000 / 朴素 F 加权（负对照） | G24 互易与能量、G23、代码行数 |
| C-MIS | power β = 2 / balance | G26、G27 的方差与 ms |
| C-GGXSample | VNDF（Heitz 2018）/ 球冠（Dupuy & Benyoub 2023）/ D(m)cos | G24 χ²、G23 方差、ms、扰动输入下的失败率 |
| C-SphereLight | 均匀锥采样 / 面积采样 | G26 方差、G31 鲁棒性 |

每个候选集输出 `candidates/p1/<set>/REPORT.md`：误差、方差、ms、鲁棒性（扰动输入后的失败率）、代码行数，保留 Pareto 前沿，其余归档并写明淘汰原因。最后的选择以选择题交给你；在你回答之前，运行时先用 ★ 默认。

## ④ 会让本实现失败的极端输入

| 输入 | 失败方式 | 兜住了吗 |
|---|---|---|
| 粗糙度 = 0 | GGX 的 D 在 α → 0 时发散，出现 0·∞ | 设计上兜住：P1D5 的 δ 分支；G30 检验连续性 |
| 光源贴面（发光球与平面相切，d = R） | NEE 的几何项 cosθ / r² 在接触点趋于无穷；锥采样的半角趋于 90° | 设计上兜住：r² 下限守卫；G31 只要求有限、统计意义上有界，并在远离接触点处对照解析解 |
| 掠射角（μo → 0）下的 GGX | G2 → 0、分母 4μiμo → 0，0/0 | 设计上兜住：μ < 2⁻²⁰ 时 f 定义为 0，pdf 同样为 0（显式分支）；G24 在 μ 网格中包含 10⁻⁶ |
| ior 恰好为 1 | F = 0，耦合因子分母 1 − Ē_s = 1；若用 Schlick 的 F0 = ((n−1)/(n+1))² = 0，也要确保没有 0/0 | 设计上兜住：G24 要求与 Lambert 逐位相同 |
| 点光源离表面极近（r → 0） | I/r² 溢出成 Inf | 语义检查 `E_LIGHT_INSIDE` 只管球体内部；平面上方 r 很小的情形由 r² 下限守卫兜住，作为第五个极端输入加进 G31 |
