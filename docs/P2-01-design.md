# P2-01 设计：XPBD 刚体、接触、摩擦、关节

> 状态：**已确认并实现**（2026-10-26，P2D1–P2D13 全部按默认；候选赛之后：求解器保留质量拆分，姿态更新换成指数映射，见 P2-02 H1–H4、R19、R20）。实现交付与实测数字见 [`P2-02-implementation.md`](P2-02-implementation.md)；实现中与本文不一致的地方记在文末「实现修订」，正文保留设计时的原样。
> 原文档对 P2 的要求：XPBD 刚体 + 接触 + 摩擦 + 关节，WGSL compute 实现。P0 登记给 P2 的裁判：穿透深度上限、恢复系数、球球冲量、单摆周期、静摩擦临界角（[golden/p0/MANIFEST.md](../golden/p0/MANIFEST.md)）；P0 登记给 P2 的极端输入：质量 ≈ 0（[P0-01](P0-01-design.md) ④）。
> 延续的约束：同一 (代码, 场景, 基底) 逐字节相同；不用浮点原子、不依赖调度顺序；位置为 Q31.32 定点（D15-A）、速度为 delta 形式；p0、p1 的全部 golden 不得改变任何字节（同 P1D11）。

## ① 一句话目标与本次决策点

**目标**：把 P0 的无约束积分器扩展为带转动的刚体 XPBD：球与球、球与平面的接触，恢复系数，静/动摩擦，distance / ball / hinge / fixed 四种关节。每一项都先有解析解或守恒律作裁判，求解器在 GPU 上并行且逐字节确定。

**决策点**（★ 为默认；回复 `P2D1A …` 或"全部默认"）：

| # | 分歧点 | 选项 | 依据 / 影响 |
|---|---|---|---|
| **P2D1** | 刚体的几何范围 | **A★** 只做球刚体（实心球，惯量 2/5·m·r²，带完整的转动状态）+ 静态平面 + 静态球。<br>**B** 加长方体（渲染要加光线-盒求交，接触要做盒-平面、盒-盒的 SAT 与裁剪）。<br>**C** 直接做 SDF 刚体（采样式接触）。 | 原文档的几何以 SDF/CSG 为主、网格只导入，长方体应在 SDF/CSG 阶段（P4）一次做对。P2 的核心是约束求解器，球的接触几何是解析的，单摆、滚动、碰撞的解析裁判都只需要球。代价：做不了"方块的静摩擦临界角"，改用球在斜面上"滚动 ↔ 打滑"的临界角 tanθ_c = 3.5·μ_s（G40）。 |
| **P2D2** | 并行求解器 | **A★** 每个子步做一次 Jacobi 迭代（Macklin et al. 2019 *Small Steps*），**gather 形式**：每个刚体按规范顺序遍历自己的全部约束，只写自己的修正量，读写分两个缓冲；不用原子操作，也不需要接触列表。Jacobi 的变体（直接相加 / 平均 / 质量拆分）进候选赛 C-Solver。<br>**B** 另外实现图着色 Gauss-Seidel（每子步在 GPU 上用 Jones-Plassmann 确定性着色）作为候选，候选赛定默认。<br>**C** 只做着色 Gauss-Seidel。 | gather + 双缓冲时，结果与调度、workgroup 划分都无关（N4、N5、N6）。Jacobi 在堆叠上收敛慢，由 G41 的穿透界兜底；A 过不了 G41 时，再按 B 补着色 GS，作为 P2 的一部分，不留到以后。B 的代价是每子步几十次 dispatch 和一套确定性着色。 |
| **P2D3** | 接触的速度级处理 | **A★** 按 Müller et al. 2020（*Detailed Rigid Body Simulation with XPBD*）：静摩擦是位置约束，动摩擦与恢复系数在位置求解之后的速度阶段处理；恢复系数用求解前的法向速度，\|v_n\| ≤ 2\|g\|h 时取 e = 0（防止静止接触抖动）。阈值和摩擦模型进候选赛（C-Friction、C-Restitution）。<br>**B** 全部在速度级处理（序列冲量风格）。 | A 与 XPBD 的位置求解一致，静摩擦不会慢慢滑走。 |
| **P2D4** | 物理材质参数放在哪里、两物体如何组合 | **A★** 新增 `physics_materials` 映射（id → `restitution`、`static_friction`、`dynamic_friction`），物体用 `physics_material` 引用，省略时取内置默认（e = 0、无摩擦）。组合规则：摩擦取 √(μ_a·μ_b)，恢复系数取 max(e_a, e_b)（Box2D 的 b2MixFriction / b2MixRestitution）。<br>**B** 参数直接写在每个物体上。<br>**C** 组合规则取平均（PhysX 默认）。 | A 与渲染材质的 `materials` 映射同构。组合规则只影响参数的直觉含义，裁判用同材质的两个物体时与规则无关。 |
| **P2D5** | 版本与迁移 | **A★** schema 升到 v3。v2 → v3 的迁移把 `xpbd_unconstrained_p0` 映射为 `xpbd_p2`，并设 `contacts: "none"`、`substeps: 1`。要求 p0、p1 的全部运行迁移后经 P2 内核**逐字节不变**（新 golden G46，同 P1 的 G32）：没有约束时修正量恰好为 0，子步公式退化为 P0 的 `dx = dt·v + dt²·g`，运算顺序与 P0 相同。<br>**B** 改写 P0 的物理核，p0 的物理 golden 按 ADR 重录。 | A 让迁移成为对求解器重构最强的回归测试。 |
| **P2D6** | 平面在物理里的语义 | **A★** 半空间：法线一侧是自由空间；第 0 步时球与平面或球与球的初始穿透超过 2⁻²⁰·r 报 `E_INITIAL_OVERLAP`。<br>**B** 双面薄板：推向较近的一侧。 | 渲染里平面仍然是双面的，只是物理把它当实心地面。B 在高速时会把球推到背面去（隧穿）。 |
| **P2D7** | 高速隧穿 | **A★** 不做连续碰撞检测（CCD）。新增运行时校验器 `tunnel.physics`：任一子步内任一刚体的位移超过 0.5·r，就判红并报告第一次出现的 (刚体, 步, 子步)。另加语义检查 `E_SPIN`：\|ω₀\|·h ≤ 0.5 rad。<br>**B** 球-球扫掠 CCD（求解子步内的二次方程）。<br>**C** 只在生成阶段用能量上界拒绝场景。 | A 宁可大声失败，也不悄悄穿过去；C 的能量上界对轻刚体极其保守，会拒绝大量正常场景。 |
| **P2D8** | 子步与迭代次数 | **A★** `physics.substeps` 进 schema，必填（1–256，无默认值），每个子步 1 次迭代（*Small Steps*）。<br>**B** `iterations` 也进 schema。 | 子步数改变输出字节，按 P1D12 的规则应进 schema；*Small Steps* 表明在同样的计算量下，"多子步、各 1 次迭代"优于"少子步、多次迭代"。 |
| **P2D9** | 关节范围 | **A★** distance（带 compliance，compliance > 0 就是弹簧）、ball、hinge、fixed；端点可以是刚体或 `"world"`。不做限位与马达（P3/P4）。<br>**B** 只做 distance 与 ball。 | 原文档要求关节。四种关节覆盖了单摆、复摆、弹簧、焊接、铰链的解析检验。 |
| **P2D10** | 质量比（P0 登记的"质量 ≈ 0"） | **A★** 语义检查 `E_MASS_RATIO`：所有动态体中最大与最小质量之比 ≤ 10⁴；G41 在 10⁴ 的边界上检验堆叠穿透界，边界上不过就收紧限制，而不是放宽穿透界。<br>**B** 不限制，只报告。 | schema 允许 10⁻⁶–10⁶ kg，比值可达 10¹²；轻重悬殊的堆叠是 Jacobi 类求解器的已知弱点。 |
| **P2D11** | 随机流 3（physics_perturbation，P0 预留） | **A★** P2 不使用，继续保留。P0 登记的"增删实体不改变其他实体"的局部性测试改为物理局部性：加入一个不与任何物体接触的远处刚体，其他刚体的状态字节完全不变（G45）。流 3 自身的局部性测试在它第一次被使用时落地。<br>**B** 新增 `physics.perturbation`（用流 3 给初始状态加微扰，打破对称）。 | 没有需求就不引入随机源。 |
| **P2D12** | 状态输出格式 | **A★** `state/step_k.bin` 保持每体 48 B 不变；新增 `state/step_k.rot.bin`（四元数 q：4 个 f32，角速度 ω：3 个 f32，再加 1 个填充 u32，每体 32 B），只在有转动动力学（`contacts` 不为 none 或有关节）时写出。JSON 状态加 `q` 与 `omega_rad_s`。<br>**B** 合并成每体 80 B 的单一记录，p0 物理 golden 重录。 | A 是 P2D5 字节不变的前提。 |
| **P2D13** | 能量校验器 V-Energy(c) 在有接触时的判据 | **A★** E_mech(n) ≤ E_mech(0) + τ_E。E_mech = 平动动能 + 转动动能 + 重力势能 + 弹簧势能；τ_E 由内核逐子步按刚体累加：每个反弹事件 m·e²·(\|v_n\|·\|g\|·h + ½\|g\|²h²)，再加推出残余穿透 δ 时的 ½·m·(δ/h)² + m·\|g\|·δ。累加用整数定点，结果确定，并作为指标输出。<br>**B** 有接触时只做 NaN 与隧穿检查，不做能量检查。 | 恢复系数用的是求解前的法向速度，它比真实碰撞速度至多大 \|g\|·h；XPBD 由位置差得到速度，推出残余穿透会产生速度。这两项是离散格式唯一能增加能量的来源，其他（无反弹接触、摩擦）只会耗散。 |

## ② 测试先行

### 新增黄金场景（p2，绑定 schema v3）

裁判分四类：**解析解**（周期、加速度、碰撞后速度）、**守恒律**（动量、角动量、能量上界）、**收敛阶**（dt 减半时误差按理论阶下降）、**契约**（迁移、拒绝语料、计划不变性）。除特别说明外，统计意义上的阈值都按 Bonferroni 取 5σ，seed 固定在场景里。

记号：h = dt / substeps（子步长），ω₀ 为系统的特征角频率，u = 2⁻²³。

| id | 场景 | 断言（数学形式） | 容忍度来源 |
|---|---|---|---|
| G35 `pendulum_period` | 质点球通过 distance 关节（compliance 0）挂在 world 锚点上，L = 1 m，θ₀ ∈ {0.05, 1.0, 2.5} rad，每个 θ₀ 跑 h 与 h/2 两组 | A1 周期（过零点线性插值求得）：\|T − T_exact\| / T_exact ≤ c·(ω₀h)²，T_exact = 4·√(L/g)·K(sin(θ₀/2))，K 用 AGM 求（K(k) = π / (2·AGM(1, √(1−k²)))）。A2 收敛阶：err(h) / err(h/2) ∈ [2^1.7, 2^2.3]。A3 约束残差：每个记录步 \|\|x − a\| − L\| ≤ 16·u·L | 单个 distance 约束、compliance 0 时，一次投影就精确落在圆上，格式是 Störmer–Verlet（x̃ = 2xₙ − xₙ₋₁ + h²g）加正交投影；按 Hairer, Lubich, Wanner《Geometric Numerical Integration》§IV.4，投影不降低基础格式的阶，预期周期误差为 O(h²)，由 A2 实测确认。常数 c 在实现时由修正方程推导并写进 `tol.derivation`；A2 的阶对 c 不敏感 |
| G36 `physical_pendulum_ball_joint` | 实心球（r = 0.2 m）用 ball 关节吊在其顶点；θ₀ ∈ {0.05, 1.0} | T_exact = 4·√(I_p / (m·g·d))·K(sin(θ₀/2))，I_p = 7/5·m·r²，d = r；判据同 G35 A1、A2；E_mech 漂移 ≤ τ_E | 检验转动惯量、锚点偏移、平动与转动的耦合；平行轴定理 |
| G37 `compliant_spring` | 无重力，球通过 compliance 为 α 的 distance 关节连到 world 锚点，初始拉伸 0.1 m | A1 周期 T = 2π·√(m·α)，误差 ≤ c·(ω₀h)²，同时检验收敛阶；A2 每个周期的振幅衰减 ≤ XPBD 隐式格式的模型界 | XPBD 的 α̃ = α/h²（Macklin et al. 2016 §3）；XPBD 对 compliance 项近似隐式欧拉，振幅每子步衰减约 (1 + (ω₀h)²)^(−1/2)，实现时推导出精确的界 |
| G38 `restitution_drop` | 无摩擦球从 1 m 高处落到平面上，e ∈ {0, 0.3, 0.7, 1}，跑 10 次反弹 | A1 相邻两次最高点之比 h_{k+1}/h_k = e² ± τ_k；A2 e = 0 时第一次接触后的反弹速度 ≤ 2\|g\|h，之后停住；A3 e = 1 时 10 次反弹后能量在 τ_E 内 | τ_k 来自两处：碰撞速度至多高估 \|g\|h，以及最高点在记录步之间的插值误差（record_every_steps = 1，用相邻三个记录做抛物线插值） |
| G39 `two_sphere_collision` | 无重力、无摩擦；正碰，质量比 m₂/m₁ ∈ {1, 3, 10³}，e ∈ {1, 0.5}；再加一组斜碰 | A1 碰后速度 v₁′ = (m₁v₁ + m₂v₂ − m₂e(v₁ − v₂)) / (m₁+m₂)，v₂′ 同理；A2 线动量相对误差 ≤ k·u；A3 斜碰时切向分量与角速度不变 | 牛顿碰撞定律；质量拆分下两体所受冲量等大反向，动量误差只来自舍入（每次修正约 4u，乘以接触子步数）。若候选赛选了"平均"，A2 会失败，这正是区分它们的检验 |
| G40 `rolling_incline` | 球放在倾角 θ 的斜面上：(a) θ = 20°、μ_s = 0.6，纯滚动；(b) θ = 30°、μ_s = 0.1、μ_d = 0.08，打滑；(c) θ = atan(3.5·μ_s) ± 2°，检验临界角 | (a) 位移 s(t) = ½·(5/7)·g·sinθ·t²，接触点滑移速度 \|v − ω×r\| ≤ τ_slip；(b) 线加速度 a = g(sinθ − μ_d·cosθ)，角加速度 α = 5·μ_d·g·cosθ / (2r)；(c) 低于临界角为滚动、高于为打滑，判类正确 | 刚体动力学的解析解；纯滚动需要的摩擦力是 (2/7)·m·g·sinθ ≤ μ_s·m·g·cosθ，即 tanθ ≤ 3.5·μ_s。这是"静摩擦临界角"在球刚体上的形式（P2D1） |
| G41 `resting_and_stack` | (a) 球静置在平面上 10 s；(b) 4 个等质量球竖直叠放；(c) 同 (b)，质量比 10⁴（重的在上），即 `E_MASS_RATIO` 的边界 | A1 全程最大穿透 ≤ τ_pen；A2 静止速度 ≤ τ_v；A3 E_mech 不超过 τ_E；A4 精确对称的竖直叠放水平位移恒为 0（逐位） | τ_pen = 10⁻³·r 是**需求**（不是推导值），三个求解器候选用同一个值；若默认候选过不了 (c)，按 P2D10 收紧质量比，不放宽 τ_pen |
| G42 `momentum_cluster` | 无重力、无摩擦、e = 1；64 个球挤成一团，初速度在生成阶段由测试工具流 4 给出；不设平面 | A1 总线动量守恒，误差 ≤ k·u·Σ\|p_i\|；A2 绕质心的总角动量守恒（无摩擦时冲量过球心）；A3 动能不增加，误差在 τ_E 内 | 守恒律；多体同时接触是区分 Jacobi 三个变体（直接相加会冲过头、平均会破坏动量、质量拆分两者都不会）的主要场景 |

### 新增校验器
- **V-Energy(c)**：按 P2D13，接触场景也检查能量。
- **`tunnel.physics`**：按 P2D7，任一子步位移 > 0.5·r 即判红，报告第一次出现的 (刚体, 步, 子步)。
- **`nan.physics`**：扩展到 `rot.bin`（四元数与角速度）。
- 负对照（同 G15）：故障注入的恢复系数增益 > 1 → V-Energy 判红；子步位移超界 → `tunnel.physics` 判红；四元数里注入 NaN → `nan.physics` 判红，并报告精确位置。

### 元测试变化
- **MT2** 新增物理精选变异，要求被 **oracle** 抓到（不只是哈希），例如：广义逆质量漏掉 (r×n)ᵀI⁻¹(r×n) 项；α̃ 忘记除以 h²；恢复系数改用求解后的速度；动摩擦误用 μ_s；四元数不归一化；质量拆分时漏乘接触数；两体的 λ 不对称（各自独立计算）；平面法线取反。
- **MT3** 性能基准加入 G42（工作量计数器新增 `physics_substeps`、`pair_tests`、`constraint_solves`）。
- **MT6** 迁移往返扩展到 v2 ↔ v3（G46）。

### 3.2 刚体状态与缓冲

- `Body`（48 B，与 P0 相同）：Q31.32 定点位置、逆质量、速度 v（f32）。
- `BodyRot`（32 B）：四元数 q（4 个 f32）、角速度 ω（3 个 f32）、1 个填充 u32；就是 `rot.bin` 的记录格式（P2D12）。
- 不随时间变化的量放在只读缓冲里：半径、逆惯量（实心球各向同性，标量 I⁻¹ = 5 / (2·m·r²)）、物理材质、关节的局部锚点与轴。
- 两个物体的位置差先在定点里做精确的整数减法，再转成 f32。因此接触法线和约束误差只在最后一步舍入一次，与物体离世界原点多远无关（D15-A 的预期用途）。

### 3.3 每个子步的 dispatch 序列（gather，双缓冲）

1. **预测**：Δx_pred = h·v + h²·g（g·h² 在 CPU 上用 f64 算好再转 f32，与 P0 的运算顺序相同）；x̃ = x + Δx_pred（定点加法）；q̃ = q + ½·h·[ω, 0]·q，再归一化（候选赛 C-Quat）。
2. **计数**：每个刚体统计自己当前活跃的约束数 n_i（接触与关节），供质量拆分用。
3. **求解**：每个刚体按规范顺序遍历：所有其他球（`all_pairs`）、所有平面、自己的关节。对每个约束：
   - **对称求值**：两个刚体对同一对的计算都按（较低排名, 较高排名）的固定方向进行，因此两边得到逐位相同的 λ。修正等大反向，线动量只受舍入影响。
   - **λ 的计算**：λ = −C / (w̃_a + w̃_b + α̃)，其中 w̃ = n·w，w = 1/m + I⁻¹·\|r × n\|² 是广义逆质量（质量拆分，Tonge et al. 2012：每个约束只看到刚体质量的 1/n），α̃ = α / h²（Macklin et al. 2016）。刚体自己的修正用**未拆分**的 w：Δx_i = Σ_c (1/m_i)·λ_c·∇C_c，于是 m_i·Δx_i 与对方的修正等大反向，线动量守恒。
   - **静摩擦**：位置约束，满足 λ_t ≤ μ_s·λ_n 时生效（Müller et al. 2020）。
   - **写出**：Δx_i 与 Δθ_i 写进第二个缓冲。
4. **应用**：x = x̃ + Δx_i（定点）；q 加上 Δθ 后归一化；v = (Δx_pred + Δx_i)·(1/h)，是 delta 形式，不做大数相减；ω 由 Δq = q·q_prev⁻¹ 求得：ω = 2·Δq.xyz / h，Δq.w < 0 时取反。
5. **速度阶段**（gather）：恢复系数用第 1 步之前保存的法向速度 v_n^pre，\|v_n^pre\| ≤ 2\|g\|h 时 e 取 0；动摩擦 Δv = −v_t/\|v_t\| · min(h·μ_d·\|f_n\|, \|v_t\|)，其中 f_n = λ_n/h²。同一阶段累加 τ_E 的两项和隧穿检查的最大位移（P2D13、P2D7）。

**退化到 P0**：没有约束时 Δx_i 恰好为 0，第 4 步的 v = Δx_pred·(1/h) 与 P0 逐位相同；ω = 0、q 为单位四元数时，第 1 步的四元数更新保持精确。所以迁移过来的 p0 场景不需要单独的快路径（P2D5、G46）。

### 3.4 确定性

- 每个 pass 只读上一个 pass 写出的缓冲，结果与 invocation 的执行顺序无关（N4）。不用浮点原子，也没有 append 列表（N5）。
- 执行计划只能在子步之间切分 dispatch / 提交（G45）。
- τ_E 与最大位移用整数定点在刚体自己的记录里累加，不跨刚体归约；读回后在 CPU 上按规范顺序求和。
- 球心重合（d < 2⁻²⁰·(r_a + r_b)）时法线取一个确定的回退方向：从较低排名指向较高排名的世界坐标轴（+z，若与平面法线平行则改用 +x），两边同样计算（④ 第 3 条）。

## 实现修订（实现后补记）

| # | 本文原设计 | 实际实现 | 原因 |
|---|---|---|---|
| R1 | 动摩擦按 Müller 2020 的写法：接触点速度改变量 ≤ h·μ_d·\|f_n\| | 改为冲量上界：摩擦冲量 ≤ h·μ_d·\|f_n\|，且不超过止住滑移所需的冲量 \|v_t\| / (w_a + w_b) | 原写法把冲量当成速度，对球来说接触点速度的变化大部分来自自转，质心只剩 2/7 的摩擦力：斜面打滑时摩擦弱了 3.5 倍（G40 实测 s = 2.357 m，理论 2.113 m）。改后 2.114 m。变异 `friction-impulse-as-velocity` 守住 |
| R2 | ω 由 Δq = q·q_prev⁻¹ 求得（Müller 2020 Alg. 2） | ω = ω_pre + Δθ/h（角速度的 delta 形式） | 每个子步 \|Δq.xyz\| ≈ h\|ω\|/2 ≈ 10⁻⁵，两个几乎相等的 f32 四元数相减，ω 每子步丢约 1%，h 越小越糟；复摆周期在 16 子步时偏 1.5×10⁻³。改后 4×10⁻⁶。变异 `omega-from-quaternion` 守住 |
